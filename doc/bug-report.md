# 🐛 Bug Report: Win Condition ไม่เช็คตัวฆาตกร

| รายการ | รายละเอียด |
|---|---|
| **วันที่พบ** | 2026-07-06 |
| **ไฟล์ที่เกี่ยวข้อง** | `server/gameLogic.js` → ฟังก์ชัน `checkEndGame()` |
| **ความรุนแรง** | 🔴 Critical — ส่งผลต่อผลลัพธ์การแพ้ชนะของเกม |
| **สถานะ** | ✅ แก้ไขแล้ว |

---

## 📋 สรุปปัญหา

เมื่อจบ turn ในช่วง voting phase ระบบตรวจสอบว่านักสืบชนะหรือไม่ โดยเช็คเฉพาะ **อาวุธ (mean)** กับ **หลักฐาน (key)** ที่ผู้เล่นทาย แต่ **ไม่ได้เช็คว่าผู้เล่นชี้ตัวฆาตกรถูกคนหรือเปล่า** ทำให้เกิด 2 สถานการณ์ผิดพลาด:

1. **ชี้ผิดคน แต่ถูกอาวุธ+หลักฐาน** → ระบบจบเกมให้นักสืบชนะ (ผิด)
2. **ชี้ถูกคน แต่ผิดอาวุธ/หลักฐาน** → ระบบไม่จบเกม ไปต่อ round ถัดไป (ถูกต้องตามกติกา แต่ผู้เล่นอาจสับสนว่าทำไมไม่จบ)

---

```
        └─ ถ้ายังไม่ครบ → รอต่อ
```

### โค้ดที่มีปัญหา (ก่อนแก้)

**ไฟล์**: `server/gameLogic.js` บรรทัด 306-314

```javascript
// ❌ เช็คแค่ mean + key ไม่ได้เช็ค player
if (
  game.guesses &&
  game.guesses.filter(
    (item) =>
      item &&
      item.mean === game.murdererChoice?.mean &&
      item.key === game.murdererChoice?.key
  ).length > 0
) {
  updates = { finished: true, winner: 'detectives' };
}
```

**ปัญหา**: เงื่อนไข filter ไม่มี `item.player === game.murderer` ทำให้ระบบไม่สนว่าผู้เล่นชี้ตัวใคร ขอแค่อาวุธกับหลักฐานตรงก็ถือว่าชนะ

### โค้ดที่แก้ไขแล้ว (หลังแก้)

```javascript
// ✅ เช็คครบ 3 อย่าง: player + mean + key
if (
  game.guesses &&
  game.guesses.filter(
    (item) =>
      item &&
      item.player === game.murderer &&          // ← เพิ่มเงื่อนไขนี้
      item.mean === game.murdererChoice?.mean &&
      item.key === game.murdererChoice?.key
  ).length > 0
) {
  updates = { finished: true, winner: 'detectives' };
}
```

## 🔄 Flow ที่ทำให้ไม่จบเกมตอน Turn 1 (ปัญหาเดิมที่ผู้ใช้แจ้ง)

```
Turn 1 (Round 1)
    │
    ├─ ผู้เล่น A โหวต: ชี้ตัว Player X (ถูกคน) + อาวุธถูก + หลักฐานผิด
    │   → checkEndGame(): mean ✅ key ❌ → ไม่ match → ไม่จบเกม
    │
    ├─ ผู้เล่น B ผ่าน (pass)
    │
    ├─ ผู้เล่น C ผ่าน (pass)
    │
    └─ ทุกคน acted แล้ว (validGuesses + passedTurns === totalVoters)
        │
        ▼
    round++ → Round 2  ← ไม่ควรจบเกมจริงๆ เพราะทายไม่ถูกครบ 3 อย่าง
                          แต่ผู้เล่นอาจเข้าใจผิดว่า "ชี้ถูกคนแล้วทำไมไม่จบ"
```

> **หมายเหตุ**: ตามกติกาเกม Deception: Murder in Hong Kong ผู้เล่นต้องทายถูก **ครบทั้ง 3 อย่าง** (ตัวฆาตกร + อาวุธ + หลักฐาน) จึงจะชนะ ดังนั้นถ้าชี้ถูกคนแต่ผิดอาวุธ/หลักฐาน → ไม่จบเกมเป็นเรื่องถูกต้อง

4. **คาดหวัง**: ไม่จบเกม, รอผู้เล่นคนอื่นโหวตต่อ

### Test Case 3: ชี้ถูกคน ผิดอาวุธ → ไม่จบ
1. เริ่มเกม มี 4 ผู้เล่น
2. ฆาตกรเลือกอาวุธ "Knife" หลักฐาน "Gloves"

1. เล่นจนถึง Round 3
2. ทุกคนโหวตหรือ pass ครบ แต่ไม่มีใครทายถูก
3. **คาดหวัง**: `finished: true`, `winner: 'murderer'`

## 📝 บันทึกเพิ่มเติม

- ข้อมูล `guess` ที่ส่งจาก client มีโครงสร้าง: `{ player: number, mean: string, key: string }`
  - `player` = index ของผู้เล่นที่ถูกชี้ว่าเป็นฆาตกร
  - `mean` = ชื่ออาวุธที่ทาย
  - `key` = ชื่อหลักฐานที่ทาย
- `game.murderer` = index ของฆาตกรตัวจริง (ตั้งค่าตอน `startGame()`)
- `game.murdererChoice` = `{ mean, key }` ที่ฆาตกรเลือกไว้ (ตั้งค่าตอน `setMurdererChoice()`)
